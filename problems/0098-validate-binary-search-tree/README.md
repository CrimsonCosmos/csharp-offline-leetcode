**Topics:** Tree, Depth-First Search, Binary Search Tree, Binary Tree
**Link (online only):** https://leetcode.com/problems/validate-binary-search-tree/

**Example 1:**
```
Input: root = [2,1,3]
Output: true
```


- The number of nodes in the tree is in the range [1, 104].
